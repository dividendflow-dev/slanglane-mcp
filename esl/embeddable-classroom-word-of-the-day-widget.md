# Embeddable "SFW Classroom Slang of the Day" Widget for Moodle, Canvas & School Websites

> Live preview & documentation: **[https://slanglane.com/esl](https://slanglane.com/esl)**

University ESL centers, high school media-literacy teachers, and language blogs can embed SlangLane's daily classroom card (100% general-audience vocabulary; all 18+ entries are strictly excluded).

## Option 1: Lightweight JavaScript Widget (Creates a Direct Dofollow Attribution Link)

```html
<div id="slanglane-esl-widget"></div>
<script src="https://slanglane.com/esl/widget.js" async></script>
```

## Option 2: Responsive Iframe (For Canvas LMS, Moodle, Blackboard, Google Sites & Notion)

```html
<iframe src="https://slanglane.com/esl/widget" width="100%" height="210" style="border:0;max-width:480px" loading="lazy" title="SlangLane SFW Classroom Slang of the Day"></iframe>
```
